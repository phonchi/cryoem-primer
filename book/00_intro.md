# Cryo-EM 單顆粒分析入門

歡迎！這是為專題生準備的自學教材，目標是在最短的路徑上，把「一般影像處理」與「cryo-EM 單顆粒分析（single-particle analysis, SPA）」串起來，並以**合成資料（synthetic data）的生成**作為第一個動手實作的完整範例。

```{admonition} 這本教材怎麼讀
:class: important
- **第 1–4 章：影像處理工具箱。** 影像即陣列、濾波與分割、傅立葉分析、小波。這些是通用工具，之後每一步 cryo-EM 處理都會用到。
- **第 5–6 章：cryo-EM 背景與流程。** 為什麼要用冷凍電鏡看蛋白質、從顯微鏡到 3D 結構的完整計算管線。
- **第 7 章：合成資料生成（本週重點）。** 用 ASPIRE 把 70S 核糖體的 3D 密度圖，一步步變成 5,000 張帶 CTF 與雜訊的模擬粒子影像，並理解每個參數背後的物理與統計意義。
```

## 為什麼從影像處理開始？

Cryo-EM 的原始資料就是**影像**——極低訊噪比（SNR 常低於 0.1）的二維投影。所有 cryo-EM 演算法，本質上都是影像處理方法在特定物理模型下的應用：

| 影像處理觀念 | 對應的 cryo-EM 步驟 |
|---|---|
| 陣列、dtype、動態範圍（第 1 章） | 讀寫 micrograph 與 MRC 格式 |
| 濾波、模板匹配、形態學（第 2 章） | 去噪、particle picking、遮罩製作 |
| 卷積定理、去卷積、Wiener（第 3 章） | **CTF 模型與 CTF 修正** |
| 多尺度分析、閾值去噪（第 4 章） | 低 SNR 影像增強 |

## 為什麼要學合成資料生成？

真實資料的「正確答案」（每張粒子的方向、平移、構型）永遠未知；合成資料則**每個變因都在你的掌控之中**。它是：

1. **理解成像模型的最好方式**——生成的過程就是 forward model：投影 → CTF → 雜訊。
2. **演算法開發的對照組**——有 ground truth 才能量化演算法的表現。
3. **研究的日常工具**——本教材第 7 章會同時展示課堂教學版（ASPIRE 基本管線）與研究等級版（發表論文所用的協定）兩種寫法。
