# `speak-human-tw` 事後摘要

本輪沿用使用者授權的「直接套用、事後摘要」模式。公式、數字、程式行為、API 名稱與 citation keys 均列為保護項。

## 全站固定替換

- 11 處「單顆粒」改為「單粒子」，包含書名、首頁、導覽與正文。
- 13 處「訊噪／訊噪比」依句意改為「訊雜／訊雜比」。
- optimization 的中文敘述統一為「最佳化」；依使用者決定保留「閾值、卷積」。
- 檔案與資料語境中的「保存」改為「儲存、記錄、保留或典藏」；生物樣品保存則維持原詞。

## 公開教材移除的內部語氣

- 移除 `provenance`、`run_manifest`、`volume_sha256`、`sha256_file` 與 `_build/synthetic` 等維護者細節。
- 移除「教材目前沒有」「不會假裝」「老師維護」「Jupyter Book build」等製作過程語氣。
- 第 7 章改成學生可直接修改 `num_imgs_default`、`output_dir_default` 的操作說明，並用中性的「適用範圍」說明模型限制。
- 圖片 caption 與正文不標示 PPTX、slide 或投影片頁碼；`images/pptx` 僅保留為內部檔案路徑。

## 教材語氣

- 01–04 的改寫以「概念、可執行例子、數值檢查、限制、Cryo-EM 連結」為順序，刪除罐頭式導言與過度肯定。
- 沒有為了增加人味而虛構作者經歷、學生故事或研究結果。

## 本輪章末檢查與獨立讀者修訂

- 11 組「理解檢查」收斂為 45 題；刪除 HOG 維度、ASPIRE 預設 offset 等版本或 API 細節題。
- 每題後方加入預設收合的「參考答案」，內容包含推導、數值例子、常見誤解與適用限制。
- 「可辯護的結果、下游驗證、其他診斷」等審稿語氣改成學生可以直接採取的檢查步驟。
- 全站改寫「不是 A，而是 B」「不只是」「不代表」「不能只靠」等制式對比句，直接說明成立條件與限制。
- 第 7 章以自然語句交代單一構形、徑向 CTF、白高斯雜訊等模型範圍，並加入每軸 ±4 pixels 的平移與置中對照。
