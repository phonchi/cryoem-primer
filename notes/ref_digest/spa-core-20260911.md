# SPA 新增核心文獻精讀（2026-09-11）

本筆記依本地 PDF 正文與方法段撰寫。`PDF p.` 為從 1 起算的檔案頁；沒有該字樣時是印刷頁碼。全文快取只保留在專案外的 `References/document_cache/text/`；此處是原創教學轉述與定位。補充材料與主文各有獨立 source ID。書目 DOI 優先核對 PDF 首頁，1998 DOI 另核對出版社頁。

## ma2019em

- Ma & Ng, *The EM algorithm*, CS229 Part IX，2019-05-13，14 PDF 頁；不是 Dempster 等人的原始 EM 論文，沒有 DOI。
- 精讀 §§1–3，PDF pp.1–8：Jensen 不等式給 log-sum 的下界；令輔助分布等於目前 posterior，可使下界在目前參數相切。Eq.(7) 是 ELBO，Eq.(8) 是 posterior，Eq.(9) 定義 ELBO。
- 正文用兩個候選姿態的權重先說明 E-step，再把完整 Jensen／KL 分解放收合區。posterior 是對未知變數的條件分布，不是新的影像觀測。
- 界線：精確 E/M-step 不降低觀測 log-likelihood；不保證全域最佳，也不保證模型符合真實資料。數值離散、截斷或近似 M-step 需另查是否仍保有單調性。引用本地日期版本；線上講義版本可能不同。

## sigworth1998

- Sigworth, JSB 122(3):328–339，DOI [10.1006/jsbi.1998.4014](https://www.sciencedirect.com/science/article/pii/S104784779894014X)。
- 精讀 pp.329–332，Eqs.(1–21)，並讀 pp.337–338 討論：單一共同 2D 訊號經旋轉、平移與白 Gaussian 雜訊產生觀測。Eq.(12) 為條件概似，Eq.(16) 對每張影像的全部姿態加權後再平均；Eq.(20) 在能量守恆的變換假設下將權重寫成相關值的指數。
- 教學動機：低 SNR 下相關函數有多個候選峰，硬選最大者會把不確定性藏起來。積分是將多個解釋保留在更新裡，不是先求平均角度再對齊。
- 界線：這是共同視角的 2D 問題，不能直接宣稱已處理未知 3D 方向。Eq.(21) 的硬對齊關係需要 posterior 集中；局部極值與初始參考仍是問題，不能把較低 reference bias 說成無偏保證。

## scheres2005

- Scheres et al., JMB 348:139–149，DOI 10.1016/j.jmb.2005.02.031。
- 精讀 pp.140–142 的 Theory 及 pp.146–147 Discussion：把隱藏變數從姿態擴成「類別＋姿態」，用多參考 Gaussian 模型共同估計代表影像與群體比例。正文條件模型與更新式把每張影像對每個類別的貢獻分散到可能姿態。
- 教學用處：二維分類不只是先對齊後跑 k-means；代表影像、類別與姿態相互依賴。責任權重必須對所有類別與姿態合計為 1。
- 界線：文中已討論 CTF 可擴充模型但有額外計算與建模成本；不可把此 2005 2D 演算法等同於後來完整 Fourier-domain MAP refinement。Discussion 明言可能收斂局部最佳，對種子仍可能敏感。

## sorzano2010

- Sorzano et al., JSB 171:197–206，DOI 10.1016/j.jsb.2010.03.011。
- 精讀 §§2.1–2.4（pp.198–201）、§§3.1–3.3 與 Discussion：CL2D 結合 correntropy、divisive vector quantization 與 robust assignment criterion。correntropy 是局部差異經 Gaussian kernel 再平均的相似度；不是把相關係數單純改名。
- 一個教學關鍵是 pp.200–201 的「乾淨大類吸走其他影像」：樣本數不同會造成類平均的雜訊程度不同，單看最大絕對相似度會偏向較乾淨類。作者比較個別類別的相似度分布來減輕此效應。
- 界線：不能把 correntropy 本身說成 posterior probability。此方法仍有 kernel、分裂及停止參數；論文模擬中各變體表現依條件改變，不能聲稱每個資料集都勝過 correlation 或 ML。

## yang2012

- Yang et al., Structure 20(2):237–247，DOI 10.1016/j.str.2011.12.007。本地是 20 頁作者稿，定位用段落標題避免混淆期刊頁。
- 精讀 PDF pp.3–4 與 Experimental Procedures pp.8–14：ISAC 分別檢查重複 reference-free alignment 的姿態穩定性與重複 clustering 的群集可重現性；EQK-means 控制群集大小，穩定粒子子集用於可靠平均。
- 教學用處：同一平均圖重複出現，不代表組內粒子是同一視角；要比較個別粒子的對齊與共同分組。等大小群集是演算法中間限制，不是生物族群等比例的假設。
- 界線：通過穩定性測試不是結構真實性的充分條件。被排除的粒子可能是少見視角或較低 SNR，不能全部判成污染，也不宜直接用最後保留類別大小估計生物族群比例。

## yang2012-supp

- 精讀 Supplement §§S1–S3（PDF pp.1–4）及 Figures S7–S10。
- S1 模擬顯示特定影像／條件下 SNR 與穩定性的急遽變化；S2 比較兩個近同質子群和混合群，多次平均圖與 FRC 相近，但個別粒子 mirror／orientation stability 可揭露差別。
- 教學可採用「平均圖可重現仍不夠」這一反例。S1 的 0.1／0.25 數值是該模擬結果，禁止提升為所有 SPA 資料的通用閾值。

## scheres2012bayes

- Scheres, *A Bayesian View on Cryo-EM Structure Determination*, JMB 415:406–418，DOI 10.1016/j.jmb.2011.11.010。檔名 Relion 指向此理論文，不是另一篇 *RELION: Implementation…*。
- 精讀 Theory pp.408–411 Eqs.(1–12)、pp.416–417 Discussion。Eq.(1) 是 CTF×Fourier slice＋noise；Eq.(6) 給頻率相依 Gaussian noise；Eq.(7) 邊際化姿態；Eq.(8) 是 Fourier coefficients 的 Gaussian prior；Eq.(9) 的重建分母加入 prior precision，Eq.(12) 是姿態 posterior。
- 教學從單一頻率的加權最小平方推到 MAP 分母的額外項，使學生理解資料弱時為何更多收縮。noise variance 隨頻率變動允許 colored noise；Fourier noise independence 仍是模型假設。
- 界線：regularization 不等於補回未觀測資訊；hyperparameter 需估計且原文有經驗調整。本文明言 overfitting 未完全消除，不應寫成使用 MAP 就免驗證。

## cheng2015primer

- Cheng, Grigorieff, Penczek & Walz, Cell 161(3):438–449，DOI [10.1016/j.cell.2015.03.050](https://www.sciencedirect.com/science/article/pii/S0092867415003700)。
- 精讀 Figure 1、Specimen Preparation（pp.439–440）、Figure 2 與 processing/reconstruction 段落：樣本最佳化和影像處理互相回饋；冰厚、不同方向、異質性與 motion 直接限制後續估計。
- 教學可從「為何不能拍一張更清楚的影像」帶出低劑量與多粒子統計。Figure 2 的 raw/corrected 平均肉眼相近，但 Thon rings 品質不同，支持不能只靠圖像看起來乾淨判斷修正。
- 界線：2015 的典型能力與限制應以當時技術背景呈現，不把當年限制冒充現行軟體上限；不是 cryo-ET 教材。

## punjani2017

- Punjani, Rubinstein, Fleet & Brubaker, Nature Methods 14:290–296，DOI [10.1038/nmeth.4169](https://www.nature.com/articles/nmeth.4169)。
- 精讀主文方法說明、Figures 1–3，連同下面 supplement 的 objective、SGD 和 branch-and-bound：ab initio 使用 marginal likelihood／posterior，SGD 以 minibatch 近似梯度；快速 refinement 透過界限排除不值得繼續搜尋的姿態區域。
- 教學用處：統計模型與數值求解分開。不同軟體可以共享邊際化想法，卻使用不同搜尋及最佳化策略。SGD 的隨機性是選取資料子集計算更新，並非假定姿態已知。
- 界線：2017 benchmark 的 runtime 依資料與硬體而定，不當作目前版本的保證。Ab initio 不需既有參考圖，仍有模型、先驗、初始化與類別數選擇。

## punjani2017-supp

- 精讀 Supplementary Note 1，PDF pp.1–5，Eqs.(1–10)。Eq.(6) 先對類別加總，再對姿態積分；該文使用 uniform mixing probabilities 與 pose prior，是實驗設定而非所有方法的必要條件。
- PDF p.4 的 noise-model 段落特別指出初始 3D model error 也需要被容納，否則很差的初始模型會使權重過早集中。近似 Hessian/step-size 與 minibatch 屬計算策略，不改變「需解釋雜訊」的動機。
- 界線：不要把這些固定先驗設定挪到一般 GMM 推導中，否則會與需估計 mixing proportions 的 M-step 矛盾。

## punjani2021

- Punjani & Fleet, JSB 213(2):107702，DOI 10.1016/j.jsb.2021.107702。
- 精讀 §§2、3.7、4.1–4.2、5.1–5.2，特別 PDF pp.11–13 Eqs.(2–11)。3D 密度寫成 consensus 加上少數線性變動模式；以已估 pose、CTF 投影各模式，再與每張影像比較。不同影像看見的是同一 3D 模式的不同 2D 投影。
- §5.2 固定 consensus、pose 與 CTF；先 noise whitening，再採 PPCA 零雜訊極限得到最小平方交替更新。Eq.(7) 僅解 latent coordinates 的均值，不能稱為保留完整 posterior covariance 的一般 PPCA E-step。Eq.(7) 的 inverse 需要對應矩陣可逆，病態時需正則化或廣義逆。
- 界線：線性模式可近似小變形，也可顯示離散差異，但大幅轉動可能用模糊／密度增減近似；動畫座標不是真實時間，模式的正負與排序也不是生化方向。未同時重新估姿態的誤差可能漏入 variability。

## sorzano2022

- Sorzano et al., Acta Cryst. D78:410–423，DOI 10.1107/S2059798322001978。
- 精讀 §2、§§4.1–4.6、§§5.1–5.3、§6。§2 將 map 誤差拆為結構 bias 與零均值波動；§5.1 Eqs.(3–4) 明示兩半共享的系統誤差可抬高 FSC；§4 描述姿態、分類、mask、normalization 與 reconstruction 的誤差來源。
- 教學用處：FSC 衡量兩份估計的一致性；兩份都錯在同一方向也可一致。保留 half-set 獨立、配合不同初始化／方法以及 mask/noise 檢查，避免把單一數字當全面正確性證明。
- 界線：本論文對 gold standard 的批判與 consensus 是作者主張，不能寫成全領域已放棄 half-set；多方法一致也可能共享 bias。這次資料夾沒有此文獨立 supplementary experiment 檔，未核實那些補充實驗，不聲稱重現。

## chung2020

- Chung et al., AMSA 5(2):283–316，DOI 10.4310/AMSA.2020.v5.n2.a4。
- 精讀 §§1.3–1.5、2–2.1、3.1–3.3，尤其 pp.293–297 Eqs.(2.1–2.5) 與 Figure 1。矩陣模型 X=M+AUBᵀ+E 保留行列結構；2SDR 在 MPCA 得到的係數上再做 vector PCA，不是原始影像做兩次相同 PCA。
- Step 1–4：擬合 MPCA、估 noise variance 並以 SURE 選矩陣秩、對 vec(U) 做 PCA、以 GIC 選第二階段秩。兩階段子空間維度分別為 p0q0 與 r≤p0q0。
- 界線：rank-consistency 是在定理的資料模型與漸近條件下；不能移植為真實 CTF colored noise、不同姿態與異質結構的無條件保證。手動指定 rank 的教學演算須明說沒有實作 SURE／GIC；2D 重建 MSE 降低不直接保證 3D resolution 改善。
